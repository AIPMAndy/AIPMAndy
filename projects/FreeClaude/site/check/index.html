    HOW IT WORKS

    看见事实，而不是猜测。

    独立实现，参考同类网络工具的可用功能设计。我们的检测对象是浏览器网络环境，不是你在 Claude 的账号状态。

    01 / 数据源

    公开 IP 与网络归属

    在你点击检测后，浏览器分别请求 ipify、ipwho.is 和可用时的 Cloudflare Meta 和 IPSnapshot IP 安全情报。IP 会被相应第三方服务器看到。IPSnapshot 的 Geo/ASN 信息由 DB-IP Lite（CC BY 4.0）提供。

    02 / 检测边界

    服务端 IP 不能冒充

    想知道 Claude 收到的真实客户端 IP，必须由 Claude 服务端或你有权限的目标端点回显。第三方网站不能独立证明。

    03 / 隐私优先

    没有账号与验证码采集

    无注册、无分析 SDK、无广告追踪；IP 默认隐藏，结果不会主动上传到我们自己服务器。STUN 测试需要用户手动触发。
