01 / WORKSPACE LAUNCHER

一个名字，
一个独立的 Claude Code 目录。

只在你亲自执行命令时创建空目录。原有 Claude Code、Claude Desktop、系统时区、浏览器和网络设置均不修改。

›可创建

字母开头，允许 a–z、0–9、连字符和下划线，最多 32 位。

创建后的本地结构
~/.freeclaude/└── workspaces/  └── my-work/    └── .freeclaude-workspace.json
不会自动执行。 页面仅生成命令，不上传工作区名或读取本机文件。系统配置目录可能仍共享 OS 级凭据或环境变量，请勿当作高强度安全沙箱。
QUICK START / TERMINALNODE 20+
STEP 01下载开源项目
git clone https://github.com/AIPMAndy/AIPMAndy.git
cd AIPMAndy/projects/FreeClaude
STEP 02创建新的配置目录
node bin/freeclaude.mjs workspace create my-work
STEP 03在这个工作区启动 Claude Code
node bin/freeclaude.mjs workspace run my-work
首次进入新工作区可能需要重新登录自己的官方账号。没有安装 Claude CLI 时，将得到明确错误提示。
管理已创建的工作区

只显示自己创建的工作区，不扫描其他 Claude 目录。

node bin/freeclaude.mjs workspace list

03 / WHAT THIS TOOL REALLY DOES

能做的做实。
做不到的说清楚。

这不是 CCBaga 的换皮产品，不复制它的浏览器引擎或身份归档机制。我们优先解决普通用户真正需要的工作区隔离与故障自查。

01

FreeClaude 网页

浏览器时区、语言、平台等实时读数；本机报告对照；命令生成器；IP 检测入口。

已提供
02

FreeClaude 命令行

创建独立配置目录、列出/检查托管目录、只读系统信息、通过环境变量启动官方 Claude Code。

已提供
03

原生身份迁移与加密备份

需要更高权限的桌面端、安全评审、加密存储与恢复事务，不能用纯网页替代。

本版本不提供
