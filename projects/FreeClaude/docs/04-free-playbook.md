# 04｜如何把 Claude Free 真正用起来

## 先说结论

**Claude Free 本身是正规的免费服务，但存在使用额度与功能边界。** 不要把免费网页聊天和付费的 Claude Code、Claude API 混成一个概念。

2026-11-17 核验官方 [Plans & Pricing](https://claude.com/pricing) 与 [Projects](https://support.claude.com/en/articles/9517075-what-are-projects)：Free 可用网页/桌面/移动对话、网页搜索、Artifacts、部分文件和代码相关能力，最多 5 个 Projects；但限制和可用功能可能调整，以实时官网/账户显示为准。

## 免费版优先做这五件事

1. **写文章前先问结构**：让 Claude 先提炼读者痛点、核心判断、三条论据，再生成初稿。
2. **读文件前先设验收要求**：要求标注事实来源、无法确定的点和待验证信息。
3. **用 Projects 管理重复任务**：将长期项目的背景和规则整理成单独的项目，提高复用率（Free 项目数量有限）。
4. **用 Artifacts 原型验证想法**：先做可展示的简单交互或文档，不要先购买额外软件。
5. **做结构化复盘**：给定已知数据和目标，让 Claude 输出“事实 / 解释 / 假设 / 下一步”，避免虚构因果关系。

## 省额度的实操方法

- **一条提示覆盖一个完整任务**：目标、输入、输出格式、限制和验收标准尽量一次给齐。
- **控制输入长度**：删去和当前任务无关的材料，引用关键片段，而不是不断堆长上下文。
- **优先验证事实**：不要因为模型回答流畅就认定数据真实。
- **合理切分工作**：简短编辑与结构提取先完成，复杂研究集中进行。
- **观察真实用量**：只有长期稳定触发免费限制，才值得去比对 Pro 等套餐。

## 常见误解

- **“免费就能一直用”**：错误。额度会限制使用，具体规则依赖官方政策和使用场景。
- **“免费 Claude 就是免费 Claude Code”**：错误。请核实 Claude Code 当前所属的官方付费套餐。
- **“登录 Claude 后就能用同一额度调用 API”**：错误。API 需要单独核对费用与认证。
- **“网上共享账号更省钱”**：未必。账号安全、条款、隐私和长期可用性风险可能远大于节省的费用。
