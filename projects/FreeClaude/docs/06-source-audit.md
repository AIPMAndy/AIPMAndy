# 06｜上传的 15 页教程：哪些值得保留，哪些不适合开源？

## 原教程覆盖的内容

源文件：用户上传的《claude使用.docx》，**15 页，主要是操作截图**。其核心步骤为：

| 原教程页码 | 主题 | FreeClaude 的处理 |
|---|---|---|
| 第 1 页 | 账号封禁风险、注册/订阅前后的常见顾虑 | 保留“问题分类”的思路，替换为官方可核验的真实风险与排查边界 |
| 第 2–4 页 | AdsPower 的下载安装和账号登录 | **不作为 Claude 的必需操作**，删去第三方工具推荐与注册链接 |
| 第 5–7 页 | 在指纹浏览器中配置环境、检查本机网络 | 改写为可解释的 DNS/HTTPS 基础诊断，不提供身份/地区伪装技巧 |
| 第 8–11 页 | 登录提供的邮箱、输入密码、经第三方网站处理 2FA、跳过恢复设置 | **不复刻**；建议使用本人邮箱，保护 TOTP 原始密钥，保持恢复设置完整 |
| 第 12–15 页 | 使用 Google 授权登录 Claude | 保留官方 Google 登录流程；新增官方邮箱安全链接的另一种路径 |

## 为什么不能直接复制原截图？

1. 源截图含有第三方个人邮箱、身份信息及验证步骤，可能关联实际账号。
2. 其中展示的 TOTP 原始密钥和验证码属于敏感凭据，发布会产生账号接管风险。
3. 原始图片的版权许可未知，未获授权不应原样作为开源资产分发。
4. 涉及指纹浏览器和环境模拟的经验性说法，不能当作官方允许的方法或永久有效的保证。

因此，本项目**只保留问题结构与合法的登录概念**，全部文字和交互重新原创；不拷贝敏感截图，不提供任何隐私凭据。

## 新版内容如何验证？

- 注册：对照官方支持地区与手机验证文件。
- 登录：对照官方 Google / 邮箱登录说明。
- 功能：对照 Claude 定价、Free Projects 和使用额度说明。
- 封禁：对照官方 safeguards / appeals 页面。
- 连通性：终端工具只验证解析与 HTTPS，不尝试判断风控原因。

## 必须避免的营销承诺

- “100% 不封号”“永久有效” —— **无法证明**。
- “Claude Code 永久免费” —— **与官方套餐边界不符**。
- “任意地区都能注册” —— **与官方支持地区要求不符**。
- “登录凭据交给他人很安全” —— **缺乏依据且风险很高**。
