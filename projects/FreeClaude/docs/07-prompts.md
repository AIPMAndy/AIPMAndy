# 07｜5 个直接可用的 Claude Free 提示词

> 这些是**文本任务模板**，不是对付费功能的承诺。可以用于 Claude Free，也可以在其他支持文本对话的 AI 产品中运行。请用真实资料替换方括号，敏感信息先脱敏。

## 1. 观点文章：不空泛、有证据

```text
你是严谨的内容编辑。请基于我的观点【填写】，写一篇 350 字以内的中文文章。
要求：第一句就是判断；至少提供 2 条可检查的事实或明确标记为待验证；
解释一个常见错误假设；结尾给出读者今天能执行的一步。
不要虚构经历和数据。
```

## 2. 产品经理：把想法落成 MVP

```text
你是一名高级 AI 产品经理。我的想法是【填写】。
请先写清目标用户、核心场景和不做什么；再给出最小 MVP 的 3 项功能、
关键流程、边界条件、验收标准，以及最应该先验证的 1 个假设。
不要空泛的增长建议。
```

## 3. 求职：找到真正的能力缺口

```text
你是一名严格但公正的面试官。岗位 JD：【粘贴】；我的背景：【填写】。
请提取关键能力，依次提出 5 个最能区分候选人的问题，
给出优秀回答需要包含的事实和证据，并指出我目前缺少哪些信息。
不要代替我编造项目经历。
```

## 4. 开发：理解现有代码

```text
你是一名资深工程师。请阅读以下代码或目录【粘贴】。
用初学者能懂的话说明：
1）它解决什么问题；2）执行入口；3）核心数据流；4）三个潜在故障点；
5）如何写最小验证测试。如果信息不足，直接列出还需要的文件。
```

## 5. 工具评估：真正省钱

```text
我正在评估工具【名称】用于【真实场景】。
请分成：官方可验证功能、必须付费的边界、隐私与迁移成本、
替代路径、最小一小时体验方案。
对不确定的价格与功能请标记“需要官网核验”，不要假设。
```

**小提示**：有外部事实、价格、区域资格、最新版本和条款等问题，模型的回答必须再次到官方网站核实。禁止让模型替你发明学员经历、项目数据或客户结果。
