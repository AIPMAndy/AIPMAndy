# 03｜高风险账号教程的六个坑（重要）

**最应该省掉的成本，是账号被盗和资料泄露后的恢复成本。** 这份清单参考上传材料里涉及的指纹浏览器、第三方邮箱、2FA 与账号安全情景，但不公开其个人截图或凭据。

## 1. 买现成邮箱 / Claude 账号

即使卖家允许你临时登录，账号可能仍由其掌握恢复方式、邮件转发规则和历史授权。后续聊天内容、付款记录、绑定设备都可能暴露；账号也可能不符合相关条款。

**更好的选择**：自己控制邮箱和 Google 账号，按官方流程注册。

## 2. 将 TOTP / 2FA 秘钥复制到第三方验证码站

TOTP 的**原始秘钥**不是一次性验证码：掌握它的人可能在未来持续生成动态验证码。原教程中展示了需要粘贴原始秘钥到第三方页面的步骤，这种做法会明显增加凭据泄露与账号接管风险。

**更好的选择**：使用自己信任的验证器，在官方账户设置中管理 2FA；不要在教程截图、Issue、聊天或不受信任的网站展示原始密钥。

## 3. 用“指纹浏览器 + 模拟环境”保证不封号

没有公开、可验证的“永久不封号”配置。IP、浏览器指纹、使用行为、支付信息可能被服务提供方综合评估，但外部教程不能据此承诺结果。

**更好的选择**：优先使用日常浏览器、本人身份和官方服务区域。不要通过指纹伪造试图绕过封禁、年龄或地区验证。

## 4. 让陌生应用读取你的浏览器数据

某些浏览器插件或自动化工具能够读取会话 Cookie、网页内容或部分授权数据。购买来路不明的管理软件、配置包、破解扩展，可能扩大账号风险。

**更好的选择**：使用正规浏览器，安装必要且可信的扩展，定期核查授权和权限。

## 5. 在公开 Issue、视频、教程中贴完整截图

截图经常包含手机号、邮箱、登录链接、一次性验证码、2FA 原始密钥、姓名、付款信息和 IP。

**更好的选择**：用局部、过期的示例；发布前彻底打码或用虚构数据重做截图。本仓库不包含原上传文档的截图。

## 6. 把所有登录失败都解释为“IP 脏了”

真实原因可能是官方故障、邮箱过滤、设备切换、账号授权问题、手机号验证失败、未满足支持地区要求或账号受限。

**更好的选择**：先区分服务端 / 本地网络 / 账户资格。见 [02｜故障排查](02-troubleshooting.md)。

## 如果你已经交出过敏感凭据

- 立即检查自己的邮箱和 Google 账户活动记录、已授权第三方应用、恢复邮箱/手机号与安全通知。
- 对泄露的密码和 TOTP 原始密钥，按账号提供方的官方安全流程更换或撤销，防止继续使用。
- 收到不明登录通知或可疑付款提醒时，先使用官方网站核实，不要从陌生消息中的链接跳转。
- 保留必要的证据用于官方支持，但不要将完整凭据转发到论坛或他人邮箱。

> 本指南提供通用安全建议，不提供规避平台限制的方法，也不保证任何账号永久可用。
